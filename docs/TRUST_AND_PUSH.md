规则优先；用用户已有模型提取难句，要求原文引用、未知项及版本缓存；不发送用户数据，不让模型决定发布、操作工具或编造入口。不可用转人工。新模板先审核；至少 20 条独立复核无严重误报后才可批准自动发布。
状态：未开始、进行中、疑似失效、结束、撤回。更正保留旧版本；可信错价先停推。事务事件触发站内消息、SSE 和 Web Push；用户×期次×事件唯一，设备投递独立。线索默认关闭、免打扰优先。降至免费或下降 ≥1 元且 ≥20% 才可另发降价提醒。过期不补推，错误更正仅告知原收件人。

## T04 当前已实现的硬门槛
- 已验证频道的必要支出只按人民币“分”计算：商品/服务实付（不含附加费）＋配送/运费＋必须新增的会员费。不涉及的费用明确填 0；未知留空。无法用该口径确认的外币活动、分期/续费不明的活动保留在线索，不按宣传汇率或返款抵扣支出。
- 权益、支出、资格和有效期各有证据摘要；共用明确的 HTTPS 核验原文、核验时间与边界。数据库拒绝任一缺失的已验证写入（包括批量更新）；有字段不等于证据属实，仍需人工审核。已验证金额展示不取自由文本。线索保留未知项的原说明。

失效：一次完整成功目录中不再出现、标题/平台/期限变化会暂停相关活跃条目的领取入口并进入复查。请求失败不当作消失，重新出现在目录不自动恢复。可人工撤回并填写公开原因；暂停、已撤回、未开始和截止后的旧链接只提示状态，不再给出操作步骤。
用户指定智谱 glm-4.7-flash，集成说明见 deploy/README.md。固定官方地址、不跟随跳转、不传用户资料、单次限长；摘要缓存键含原文、模型、提示版本。四项逐字引文须回到提供的原文，未识别的字段为 null；能匹配文字不等于证明活动属实，仍不允许由模型发布或验证。当前不自动批量调用。

### 站内消息（T06 第一批）
发布、版本审计与站内消息在 PostgreSQL 同一事务提交，批量更新也覆盖，回滚不留消息。以“同活动期次的同一用户最近一次实际通知实付”为降价比较基准，不用相邻两次采集的报价；多条订阅同时命中同一版本只写一条。更正只告知此前收到该活动站内提醒的人。消息链接显示最新活动状态；退回草稿不显示原内容。迁移不向用户补发历史存量，预览匹配不创建消息。
直接发布和预定开始共用订阅匹配、费用及去重规则。预告只记一个待唤醒活动；到时间后锁定活动、以最新版本派发并清理任务，撤回会移除任务。迁移只登记未来预告，不重放历史；自然到期更正策略尚待完善。站内记录不等于实时弹窗、系统推送或实际已读。

### 设备提醒（T06 第二批）
已授权的每台设备独立排队；入队与站内消息同事务，首次部署不补发。发送普通活动前重查有效期、频道、订阅和状态。免打扰按登记设备时区的 22:00–08:00 延后，测试按钮可即时自测。短暂故障最多尝试三次；404/410 清除失效端点。发送受理不能证明系统显示。每个浏览器环境的真机验收指标不变。

夜间队列不会按每五分钟轮询同一消息；按该设备当地 08:00 唤醒，再检查订阅、有效期和价格。若活动会在可发送前到期，则取消该设备的外推。主动关闭免打扰会唤醒尚未尝试的延后消息，不解除网络退避。已经有更新消息的旧普通通知不再补发；若当前已核实实付高于降价提醒记录的实付，即使没有新提醒也取消这一条。站内历史不删除。

### GLM 真实小样本评测（2026-11-18，未通过可用性门槛）
样本来自[上海文旅局活动公告](https://whlyj.sh.gov.cn/cysc/20261030/2e5bfead0a34468b935d97ba5180dd24.html)，单页拆成观光车、博物馆、兑换券、早鸟票、动物园五段。只提交公开条款；无用户信息，不复制整页。评判项为权益、必要实付、资格、可获得优惠的截止时间。折扣率不等于支付金额，兑换期限不等于购券期限；同时有成人和双人价格不能只摘一档。脚本在调用前固定关键事实和空值预期，锚点匹配不替代语义复核。
- 下载该页到本机临时 HTML，运行 `python3 scripts/evaluate_glm.py /tmp/ht-eval-sh.html` 默认仅检查样本。整组摘要 10f7bfe2514155eac18e25835778d419fe1157c12e32cea66ddcbeae157468d6；若变化先重审，不直接沿用旧评估。获准测试时用 `--case bus --live` 先查一条；授权、权限或限流响应后当批停止。评测缓存事务回滚，不发布情报或通知。
- 首轮 extract-1 请求 5 条，可评分结构 0 条（HTTPError 3、ValueError 1、TimeoutError 1）。首轮未取得细分状态码，不能全归因限流，也不能把该 ValueError 当成错价。之后仅对 bus 复诊：HTTP 429、供应商码 1305，未继续调用。未取得 usage，费用未知，不写成免费。样本只有一个发布方，即使全部通过也不足以批准自动发布。
- 结论：本轮有效结果率 0/5；没有有效结果，**字段准确率不可计算**。保留原有人工核验，不扩大 AI 自动化；待供应侧限制解除后，先单条成功再继续。不要为取得漂亮指标反复重试或把拒绝条目移出分母。

购物的实付拆分：如果为领取赠品必须先另购商品，把这笔**最低新增实付**计入 payable_fen，并单独填 required_purchase_fen 为其子项。商品 + 配送 + 必须新增会员费仍是合计口径，不再重复累加另购支出。无需另购须有依据后填 0，别把未知填 0。只知道券前小票门槛、不能确认叠加后最低实付时不能据此转已验证。0014 在数据库拒绝已验证购物缺该子项或商品实付低于子项；此一致性约束不代替人员如实录入或筛掉无价值满赠。
