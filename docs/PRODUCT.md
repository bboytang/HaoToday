# 产品基线
面向中国大陆公众。做正式网站，逐步放行注册，不做一次性演示站。范围只有购物、生活服务、数字权益；排除银行、运营商、支付渠道福利，按福利成立条件而非付款工具分类。
优先零元免邮、低价实物、可复算叠加、商户直接福利、发行方限免。排除普通降价、高消费、拉人、抽奖、付费续约伪免费、不确定返款。
游客读公开详情和原链；注册后收藏、订阅、反馈和管理设备。四入口：首页精选／情报搜索筛选／订阅消息／我的。详情首屏：权益、真实支出、资格、状态；下方列出步骤、入口域名、核验边界、时间与反馈。线索与已验证分栏。更新不抢占滚动位置。后台提供审核、更正、来源停用、投递故障处置。
原创移动优先，使用清单而非促销海报；状态有文字，覆盖窄屏、桌面、键盘、空结果、加载失败、过期与权限拒绝。不做用户投稿、社区、返利、代领、自动下单、付费会员。
