# 产品基线
面向中国大陆公众。做正式网站，逐步放行注册，不做一次性演示站。以购物平台实物羊毛为主，生活服务和数字权益仅作次要补充；排除银行、运营商、支付渠道福利，按福利成立条件而非付款工具分类。
优先零元免邮、低价实物、可复算叠加、商户直接福利、发行方限免。排除普通降价、高消费、拉人、抽奖、付费续约伪免费、不确定返款。
游客读公开详情和原链；注册后收藏、订阅、反馈和管理设备。四入口：首页精选／情报搜索筛选／订阅消息／我的。详情首屏：权益、真实支出、资格、状态；下方列出步骤、入口域名、核验边界、时间与反馈。线索与已验证分栏。更新不抢占滚动位置。后台提供审核、更正、来源停用、投递故障处置。
原创移动优先，使用清单而非促销海报；状态有文字，覆盖窄屏、桌面、键盘、空结果、加载失败、过期与权限拒绝。不做用户投稿、社区、返利、代领、自动下单、付费会员。

首页将最近三项有明确开场时间的已发布预告单列，注明核验频道，不计入当下可领取的精选或线索数。预告可查看成本、资格和核验边界，可收藏；未开场不提供领取步骤及办理链接，取消后不再显示旧条件。


## 2026-11-20 优先级修订（用户确认）
主线是京东、淘宝/天猫、拼多多、抖音商城等购物平台的实物机会：零元免邮、0.01/1 元等低价实物、低门槛可复算叠加。不能用普通优惠券、一般打折或副板块数量冒充购物供给。先核对 SKU/规格、资格、最低新增实付、运费和有效期；不明保持待核实。
生活服务只考虑大众高频消费的明确省钱机会，例如外卖、奶茶、打车的低门槛免单或极低实付。不是收集所有免费活动：停止新增公益电影、讲座、展览、景区地方身份免票、指定设备贴膜等本地活动。无需为了凑覆盖继续研究公共文化数据。数字限免不作为下一阶段扩源重点。
本次只调整采集和运营方向，不删除分类/数据库结构、不推翻已验模块。既有非主线记录保留出处与历史；后续不补录、不扩展，不声称现有数字来源已证明购物能力。
首页首个权益区为购物羊毛，已验证购物与待核实购物各有直达入口；其他已核实权益独立排列，不充购物精选。无购物数据时显示真实空态，不生成占位商品。分类切换保留购物过滤。
购物抢先线索可以展示有真实供应方报价、但尚未完成结算核验的具体商品，标题和支出区必须明确待核实项；不得宣称包邮、普适资格或已成功购买。报价低本身不构成已验证；线索不进入已验证/零支出筛选，默认不外推。首次体验项只人工挑选，不批量倾倒目录。
