# 来源与质量
发现目录与核验详情分开。候选：数字发行方的限免目录；购物品牌活动目录或获准联盟流；生活服务品牌活动公告。候选不代表获准或已接入。登记主体、入口、监测及发布依据、额度、复核日期、负责人、停用方式；权限不明不得生产采集。
优先订阅/授权 API，再 HTTP 增量、条件请求、规则区差异，只有动态且获准的页面用 Playwright。授权会话的 HAR/XHR 只辅助研究；不重放令牌或绕过限制。去重、限频、异常退避、单源熔断，解析缺字段同样告警。
基线存量、人工录入、真实新增、历史回放分别计数。第 7/14 天分析而非阻塞开发。14 天目标 ≥20 个真实新增、≥7 天、≥3 主体；已验证至少 20 条独立复判、准确率 ≥95%、严重误报 0；随机审过滤前候选 ≥100 条，营销剔除 ≥90%、有价值保留 ≥80%。快源已知首发时间 P90 ≤15 分钟；未知报时间区间。抽查 ≥10 次真实状态变化。单源可解析周期 ≥95%。分来源记录每条有效成本与审核分钟，样本不足明确标识，不降标准补量。

### 内地生活实例 · 人工发现与自动新增分开
[2026-11-16 陇南市文广旅局公告](https://www.longnan.gov.cn/zwzx/bmdt/73386643.html)：内测 #2 只概述三处免首道门票的景区，半价项目不纳入，陇南户籍和有效证件原件为硬条件。线下办理，链接是官方说明而非线上购票入口。未核实每日开放、预约、余量或实际入园，展示为线索，不填全程零元。人工查阅公开事实、独立撰写、仅链接原文；没有开通该站自动采集。
另查[上海文旅活动汇总](https://whlyj.sh.gov.cn/cysc/20261030/2e5bfead0a34468b935d97ba5180dd24.html)：乐高乐园促销的购券期限与入园期限不同，11 月 18 日已经不能按该条款新购券；未发布。不要把同一公告所有段落视为同一活动。
来源报告的 manual_candidates 只数人工批次，与 baseline_candidates、new_candidates 分列；人工发现不计成功采集日。人工源 enabled=false 表示没有监控授权或定时任务，不表示官网公告失效。

### 数字权益候选初筛 v1
每次完整读取 GamerPower 游戏目录时，在内存中检查来源的英文领取步骤，不调用模型、不保留步骤全文。内部记录规则版本、理由、标准化步骤摘要及队列；同批次 Run.counts.triage 记录分布。抽奖/邀请指引暂不优先，高门槛积分/付费条件单独搁置；有直领动作且有格式可读的截止时间才进优先复核，其他仍可人工查看。期限不推断时区，优先不等于有资格、免费或活动仍有库存。英文短语规则并不穷尽排除条件，绝不据此自动发布。
在受保护后台的发现记录中按“初筛队列”过滤，“优先查原始规则”内先列新增再列基线。已下目录的不再占优先队列；请求失败不做移除判定。对于已公开的条目，已知步骤内容改变或新发现高门槛时暂停指引；恢复需人工核验。enriched 是给旧存量补字段，不计上游变化或新发现。
